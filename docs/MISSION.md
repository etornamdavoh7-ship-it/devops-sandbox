# Mission Statement: DevOps Sandbox

## Purpose
The objective of this sandbox is to master Git, GitHub, CI/CD automation (GitHub Actions), and DevOps security practices through deliberate, hands-on "break and fix" scenarios. 

Rather than just reading about commands, we are actively simulating a multi-developer environment. We will intentionally trigger errors, permission blocks, and merge conflicts to build muscle memory for real-world DevOps troubleshooting.

## Learning Objectives
1. **Version Control:** Master Git commands, branching strategies, and conflict resolution.
2. **Repository Management:** Enforce security and workflow rules using GitHub Branch Protection.
3. **Continuous Integration (CI):** Automate code checks and Docker image builds using GitHub Actions.
4. **Security:** Implement modern authentication methods (like OIDC) for secure deployments.

## Methodology
- **The "Single-Account, Multi-Terminal" Simulation:** We will act as both Senior and Junior developers locally to simulate a team environment.
- **Document Everything:** Every command, issue, and solution will be logged in this `docs/` directory to serve as a future reference guide.
